# Zippio

広告・アカウント・通信を使わない、個人用 Android 圧縮・解凍アプリです。

## 対応範囲

| 形式 | 圧縮 | 解凍 | パスワード |
| --- | --- | --- | --- |
| ZIP | 対応 | 対応（PPMd を含む） | 対応（AES ZIP） |
| 7z | 対応 | 対応 | 対応 |
| RAR | 非対応 | 対応 | 対応 |

RAR の作成は RAR 形式のライセンス／仕様上、アプリには含めません。分割アーカイブは、この初期版では対象外です。

PPMd（ZIP 圧縮方式 98）を含む ZIP は、解凍時に 7-Zip エンジンへ自動的に切り替えます。ZIP の作成方式は従来どおり Deflate です。

## 0.2 の改善点

- 解凍前に、アーカイブ形式・項目数・ファイル数・展開後のおおよその容量を確認できます。危険な展開パスは、この段階で拒否します。
- 大量のファイルや大容量展開になりそうなアーカイブには、空き容量を確認する注意を表示します。
- パスワードの表示／非表示を切り替えられるため、入力ミスを減らせます。
- ファイル管理アプリの「開く」または「共有」から ZIP / 7z / RAR を Zippio に渡し、そのまま解凍できます。暗号化アーカイブは、受け取り後にパスワードを入力してから解凍してください。

今後の候補は、複数フォルダの一括圧縮、処理の中断、アーカイブ内容の個別ファイル一覧です。いずれも大量ファイルでの操作性を確認してから追加する想定です。

## プライバシーと安全性

- Android の標準ファイル選択画面（Storage Access Framework）だけを使い、ストレージの広範な権限は要求しません。
- 処理するファイルは一時的にアプリのキャッシュへ置き、完了・失敗後に削除します。
- 展開パスを検証し、アーカイブ内の `../` などによる意図しない場所への書き込みを防ぎます。
- 既存ファイルは上書きせず、同名時には連番を付けます。

## Android Studio でのビルド

1. JDK 17 が同梱された最新の Android Studio でこのフォルダを開きます。
2. SDK Platform 35（または `app/build.gradle` の `compileSdk` と同じバージョン）をインストールし、Gradle Sync を実行します。
3. 端末またはエミュレータを選び、`Run` を実行します。

この環境には Android SDK と JDK 17 が入っていないため、APK のローカル生成はまだ実行していません。
